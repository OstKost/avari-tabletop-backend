# Шаблоны и интерфейс

- Интерфейс состоит из Go `html/template` в `web/templates/layouts`, `pages`, `partials`; данные передаются из `internal/handler`. Сохраняйте имена `define` и соответствие полей шаблонов структурам данных.
- Проект использует HTMX, Alpine.js и Tailwind через CDN, а чат — JavaScript/SSE. Для изменённого действия проверьте цель `hx-target`, замену фрагмента, состояние загрузки/ошибки и обычную навигацию, если она предусмотрена.
- Не вставляйте непроверенный HTML из BGG, чата или правил в шаблон. Сохраняйте доступность форм, кнопок и навигации с клавиатуры, включая мобильный экран.
- После изменения шаблонов запустите тесты рендерера в `internal/handler` и при доступном браузере проверьте затронутый сценарий. Внешние CDN требуют сети для полного отображения.
